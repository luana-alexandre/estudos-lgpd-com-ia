# Mini Guia de Estudos — LGPD com Apoio de IA e NotebookLM

## Objetivo

Este projeto foi desenvolvido como desafio prático da DIO utilizando o NotebookLM e ferramentas de Inteligência Artificial para apoiar o processo de aprendizagem.

O objetivo deste material é consolidar os principais conceitos da Lei Geral de Proteção de Dados (LGPD), documentando resumos, fontes utilizadas, prompts aplicados e aprendizados obtidos ao longo do estudo.

---

# O que é a LGPD?

A LGPD (Lei Geral de Proteção de Dados — Lei nº 13.709/2018) é a legislação brasileira responsável por regulamentar o tratamento de dados pessoais por empresas e organizações.

Seu principal objetivo é garantir:
- Privacidade;
- Segurança;
- Transparência;
- Controle dos dados pelo titular.

---

# Principais Conceitos Aprendidos

## Dado Pessoal
Informação capaz de identificar uma pessoa.

## Dado Sensível
Dados relacionados à saúde, biometria, religião, opinião política e outros dados que exigem maior proteção legal.

## Consentimento
Autorização dada pelo titular para utilização dos dados pessoais.

# Prompts Utilizados e Insights Obtidos

Durante o desenvolvimento deste mini guia, foram utilizados prompts estratégicos no NotebookLM e em ferramentas de Inteligência Artificial para aprofundar o entendimento da LGPD, simplificar conceitos jurídicos e transformar conteúdos complexos em explicações mais acessíveis.

---

## Prompt 1

```txt
Explique LGPD como se eu tivesse 10 anos.
```

### Objetivo
Compreender os fundamentos da LGPD de maneira simples e intuitiva antes de avançar para conceitos técnicos.

### Resultado Obtido
A IA utilizou exemplos do cotidiano, como cadastros em lojas e aplicativos, para explicar como empresas coletam e utilizam dados pessoais.

### Aprendizados
- A LGPD protege informações pessoais;
- Empresas precisam pedir autorização para utilizar determinados dados;
- O titular dos dados possui direitos sobre suas informações.

### Dificuldades Encontradas
No início, os termos jurídicos tornavam a compreensão mais difícil. O uso de analogias facilitou bastante o entendimento inicial.

---

## Prompt 2

```txt
Qual a diferença entre dado pessoal e dado sensível?
```

### Objetivo
Entender as classificações de dados existentes na LGPD e os diferentes níveis de proteção exigidos pela lei.

### Resultado Obtido
A IA explicou que dados pessoais identificam uma pessoa, enquanto dados sensíveis envolvem informações mais delicadas, como saúde, biometria, religião e opinião política.

### Aprendizados
#### Dados Pessoais
- Nome;
- CPF;
- Telefone;
- E-mail.

#### Dados Sensíveis
- Dados médicos;
- Biometria;
- Religião;
- Origem racial;
- Opinião política.

### Dificuldades Encontradas
A principal dificuldade foi compreender por que alguns dados exigem proteção reforçada. Após os exemplos fornecidos pela IA, ficou mais claro o risco de discriminação e exposição indevida.

---

## Prompt 3

```txt
Explique o papel do controlador e operador na LGPD.
```

### Objetivo
Compreender os agentes envolvidos no tratamento de dados pessoais dentro das organizações.

### Resultado Obtido
A IA explicou que:
- O controlador toma as decisões sobre os dados;
- O operador executa o tratamento em nome do controlador.

### Aprendizados
#### Controlador
Responsável pelas decisões relacionadas ao uso dos dados.

#### Operador
Executa atividades de tratamento seguindo instruções do controlador.

### Exemplo Prático
Uma empresa de varejo pode atuar como controladora dos dados de clientes, enquanto um software terceirizado de CRM pode atuar como operador.

### Dificuldades Encontradas
No início, os papéis pareciam semelhantes. Os exemplos práticos ajudaram a visualizar a diferença entre quem decide e quem executa o tratamento dos dados.
